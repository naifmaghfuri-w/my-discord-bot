# الخط العربي لبطاقات المهام

بطاقات المهام (الصور) تحتاج خطاً عربياً حتى يظهر النص صحيحاً. حمّل خط **Cairo** (مجاني) من:
https://fonts.google.com/specimen/Cairo

من الملف المضغوط الذي تحمّله، خذ:
- `Cairo-Bold.ttf` ← أعد تسميته إلى **`Bold.ttf`** وضعه في هذا المجلد
- `Cairo-Regular.ttf` ← أعد تسميته إلى **`Regular.ttf`** وضعه في هذا المجلد

بدون هذين الملفين، البوت يطبع تحذيراً في السجل والبطاقات تُرسل كنص فقط (بدون صورة).
